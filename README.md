# Interest Rate Modelling

The idea behind this repository is to collect a series of notebooks presenting models and methodologies for modelling interest rates and pricing interest rate derivatives.

At the moment, the only notebook available (Agh!) covers the [Vasicek model](https://en.wikipedia.org/wiki/Vasicek_model) and its calibration for forecasting interest rates over a multi-year horizon. See the final section of this README for possible future directions.
